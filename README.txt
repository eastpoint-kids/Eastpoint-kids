EASTPOINT VINEYARD KIDS HUB

WHAT'S INCLUDED
- index.html = all page wording, dates and links
- styles.css = Eastpoint colours and design
- script.js = team scores + simple interactive buttons

HOW TO PREVIEW
Double-click index.html on a computer, or upload all three files to a GitHub repository and enable GitHub Pages.

EASY THINGS TO EDIT
1. Teaching theme / memory verse:
   Open index.html and search for "Following Jesus Together".

2. Event dates:
   Open index.html and search for "COMING UP".

3. Worship playlist:
   Search index.html for "Open Kids Playlist" and replace href="#" with your Spotify or YouTube playlist URL.

4. Official logo:
   The current header is a CSS/text treatment so the site works immediately.
   When you have your official Eastpoint Vineyard Kids PNG/SVG file, it can be swapped in.

GITHUB PAGES
1. Sign into github.com
2. Create a new PUBLIC repository, e.g. eastpoint-kids
3. Upload index.html, styles.css and script.js
4. Open Settings > Pages
5. Under Build and deployment choose "Deploy from a branch"
6. Choose main / root and Save
7. GitHub will show the website address once published.

NOTE
Review safeguarding wording, collection arrangements, allergies, ages and SEN provision against your church's actual procedures before publishing.
